# AntiFishBot 🎣

AntiFishBot is a professional-grade security solution for Minecraft servers, specifically designed to detect and prevent automated fishing bots. It uses a combination of behavioral analysis and multi-layered verification to ensure a fair environment for all players.

AntiFishBot 是一款專業級的 Minecraft 伺服器安全插件，專為偵測與防止自動釣魚機器人而設計。它結合了行為分析與多層次驗證機制，確保所有玩家都能在公平的環境下遊玩。

## ✨ Features | 功能特色

- **Fishing Analyzer**: Advanced monitoring of fishing patterns, timing, and player movement to identify suspicious activity.
- **Chat Verification**: Sends interactive chat challenges that bots cannot easily solve.
- **GUI Verification**: Displays a randomized GUI menu that requires manual interaction to prove the player is human.
- **Trap Manager**: Cleverly placed traps to bait bots and trigger immediate verification or alerts.
- **Automated Actions**: Configurable punishments including alerts, kicks, or bans for confirmed bots.
- **Real-time Logging**: Comprehensive logs of fishing activities and verification results.

- **釣魚分析器**：進階監控釣魚模式、時機與玩家移動，精準識別可疑行為。
- **聊天驗證**：發送機器人難以解決的互動式聊天挑戰。
- **GUI 驗證**：顯示隨機生成的 GUI 選單，要求手動點擊以證明玩家身分。
- **陷阱管理**：巧妙設置陷阱誘捕機器人，並觸發即時驗證或警報。
- **自動化處分**：可自定義對確認為機器人的玩家進行警告、踢出或封鎖。
- **即時日誌**：詳盡紀錄釣魚活動與驗證結果。

## 🛠️ Installation | 安裝方法

1. Download the `.jar` file.
2. Place it in your server's `plugins/` folder.
3. Restart the server.
4. Customize the verification settings and thresholds in `config.yml`.

## 📜 Commands | 指令

- `/antifishbot` - Main administrative command.
- `/antifishbot verify <player>` - Manually trigger verification for a player.

## 🏗️ Development | 開發環境

- **Language**: Java 21
- **API**: Spigot 1.20.x
